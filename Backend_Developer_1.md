# Backend Developer 1 – Authentication, Users, Wallet

## Responsibilities
- JWT Authentication
- Register/Login
- Email Verification
- Forgot/Reset Password
- Two-Factor Authentication (OTP)
- RBAC (Customer, Loan Agent, Admin)
- User Profile APIs
- Wallet APIs

## Deliverables
- REST APIs with validation
- Secure password hashing
- Refresh token support
- Wallet CRUD and transaction-safe balance updates
- Swagger/OpenAPI documentation
- Unit tests

## Prompt
You are the Backend Developer responsible for authentication and user management in the FlowFi fintech platform.

Build production-ready Express.js APIs using Node.js, MongoDB, JWT, bcrypt, and Mongoose.

Requirements:
- Follow MVC architecture.
- Validate all inputs.
- Hash passwords with bcrypt.
- Implement JWT access and refresh tokens.
- Implement email verification and password reset flow.
- Add OTP-based 2FA.
- Implement RBAC middleware.
- Create profile management APIs.
- Create wallet APIs with atomic balance updates.
- Write reusable middleware, error handling, logging, and API documentation.
